# Price Site — сайт-реестр цен

Читает ту же базу PostgreSQL, что заполняет Telegram-бот. Отдельного переноса
данных не требуется — что бот записал, то сайт сразу показывает.

## Возможности
- Вход для сотрудников по общему паролю
- Каталог материалов с фильтрами по категории, поставщику и поиском по названию
- История изменения цены по каждой позиции
- Страница "Дубликаты" — находит позиции у одного поставщика, отличающиеся
  только регистром/пробелами (значит, вероятно, это один и тот же материал)

## Деплой на Railway

1. Создай отдельный репозиторий на GitHub (например `price-site`), залей туда
   все файлы из этого проекта.
2. В том же Railway-проекте, где уже есть бот и Postgres, добавь новый сервис:
   **+ Add → GitHub Repo → price-site**.
3. В Variables этого сервиса добавь:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `SITE_PASSWORD` — любой пароль, который сообщишь сотрудникам
   - `SECRET_KEY` — любая случайная длинная строка (например, просто настучать
     что-то на клавиатуре, главное чтобы никто не угадал)
4. Deploy.
5. В Settings этого сервиса включи **Networking → Generate Domain**, чтобы
   получить публичный адрес сайта (что-то вроде `price-site-production.up.railway.app`).

## Ограничения этой версии

- Пароль один общий на всех сотрудников (без отдельных логинов) — этого
  достаточно для MVP; если понадобится разграничение прав — легко добавить
  позже отдельные аккаунты.
- Показывается максимум 500 позиций за раз — если материалов станет больше,
  нужно будет сузить фильтр (или добавим постраничную навигацию).
